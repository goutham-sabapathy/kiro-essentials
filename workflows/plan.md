# Workflow: Plan

Create a detailed implementation plan for a feature or task.

## Usage

> "Plan the implementation of real-time notifications"
> "Create a plan for migrating to PostgreSQL"

## Process

Follow the [writing-plans](../skills/writing-plans.md) skill:

1. **Clarify ambiguity** - Ask questions before guessing
2. **Analyze the codebase** - Understand current architecture
3. **Write the plan** with:
   - Specification and success criteria
   - Context loading commands
   - Tasks grouped by subsystem
   - Verification commands per task
4. **Save to** `**/plans/YYYY-MM-DD-<feature-name>.md`
