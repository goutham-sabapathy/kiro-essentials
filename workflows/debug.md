# Workflow: Debug

Start systematic debugging session for a bug.

## Usage

> "Debug this error: TypeError: Cannot read property 'id' of undefined"
> "Debug why the login flow is failing"

## Process

Follow the [systematic-debugging](../skills/systematic-debugging.md) skill:

1. Understand the bug and gather reproduction steps
2. If logs are involved, use [reading-logs](../skills/reading-logs.md) for efficient analysis
3. Systematically investigate the codebase
4. Form and test hypotheses
5. Implement a fix for the root cause
6. Verify the fix thoroughly
